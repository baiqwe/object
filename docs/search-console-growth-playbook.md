# Search Console Growth Playbook

Last reviewed: 2026-10-25

## Purpose

This is a distribution and monitoring guide for Random Object Generator. It is not a link-buying or bulk-posting plan. Each public mention should point to a genuinely useful activity, generator, or example that fits the community where it appears.

## Search Console Review Cycle

Review the Google Search Console Performance report every 28 days, using the previous 28 days as the comparison period.

Prioritize a page when it has both meaningful impressions and one of these signals:

- Average position from 8 to 20 with a weak click-through rate.
- Average position from 20 to 40 and a query clearly matches an existing tool or guide.
- A query whose wording exposes a missing use case, not merely a keyword variation.

For each selected page, record the primary query, impressions, clicks, CTR, average position, landing page, intended visitor task, and the change made. Do not create a new URL until the existing relevant page cannot answer that task well.

## Community Distribution

### Reddit

Post only where the activity itself is relevant, such as art-practice, teaching, ESL, tabletop-game, or writing-prompt communities. Read each community rule before posting. Lead with a complete activity format, a short example result, and why it was useful; link to the relevant page only when links are allowed and genuinely help the reader. Do not use vote exchanges, repeated reposts, disguised promotion, or comments that add no answer beyond a link.

### LinkedIn

Publish short practitioner posts for teachers, facilitators, learning-designers, and workshop hosts. Each post should contain a complete small activity, the audience it serves, and a clear outcome. Link to a matching generator as optional supporting material, not as the entire post. Reuse only verified engagement learnings, not generic claims about traffic or ranking.

## Quality Gate Before Any Promotion

- The linked page has a clear title, self-referencing canonical, index/follow robots tag, and sitemap entry.
- The page offers an activity or workflow that someone can complete without another purchase or sign-up.
- The example objects match the generator's actual object pool.
- The page has a relevant next-step internal link, but no unrelated link block.
- A community post is reviewed for local rules and written in the community's language.

## Avoid

- Buying links, link exchanges, automated outreach, or mass submissions.
- Creating near-duplicate pages for every query variation.
- Publishing a post that promises a result the generator cannot provide.
- Using AdSense placements, advertising language, or click requests as a distribution tactic.
